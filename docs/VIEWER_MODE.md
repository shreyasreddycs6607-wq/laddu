# Viewer Mode (your phone)

Bottom navigation: 🏠 Home · 📺 Live · 🔔 Alerts · 📊 Activity · ⚙️ Settings.

* **Home** — camera name + 🟢/🔴 status, tap-to-watch card, dog / movement / barking status, today's movement count, barking count, dog-seen duration. Camera switcher if you have several.
* **Live** — WebRTC video + audio. Mute, snapshot (saved to Pictures/Laddu), reconnect, fullscreen, quality Low/Medium/High, connection state. Streaming stops when you leave the screen to free the camera phone. Optional "Wi-Fi only".
* **Alerts** — chronological events with filters All / Barking / Movement / Dog / System. Tap for details: type, time, duration, confidence, snapshot/clip (if uploaded) and **VIEW LIVE**.
* **Activity** — today / 7 days: dog presence, movement events, barking events, howling (simple bar charts).
* **Settings** — remote camera controls (resolution, front/rear, AI toggles, sensitivities, clip lengths, *Restart monitoring*), notification switches, network, theme, account, *Manage camera* (rename, revoke viewers, unpair / remove).

## Pairing
Add camera → scan the QR on the camera phone. Tokens are one-time and expire in 5 minutes; reusing/expired codes show a clear error.

## Notifications
Tap → Alert details → VIEW LIVE. See [FCM_SETUP.md](FCM_SETUP.md).
